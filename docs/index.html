What This Project Does

🔬

Sensor Data Simulation

Generates 1,050 realistic water sensor readings — pH, turbidity, chlorine, and flow rate — with 50 injected anomalies.

🧠

Isolation Forest Model

Trains an unsupervised ML model that learns normal water behaviour and flags deviations without needing labelled data.

📊

Visual Report

Generates a 3-panel dashboard — scatter plots and anomaly score timeline — exported as PNG and CSV.

🚀

CI/CD Pipeline

GitHub Actions runs Pylint, multi-version CI tests, and weekly security scans on every push automatically.

How It Works

01

Generate Data

Run generate_data.py to create sensor readings with realistic noise and injected anomalies.

Train Model
